## Overview

A complete, production-ready, multi-page website developed for **BJ VISA CONSULTANCY**. Built using semantic HTML5, modern CSS3 with custom variables, and vanilla ES6+ JavaScript, styled using Bootstrap 5 and customized to match the brand identity established by the official BJ Visa Consultancy logo and brochures.

The design adheres to the defined luxury, trusted, and corporate visual palette:
- **Deep Navy:** `#062B5C`

## Global Features & Assets

- **Responsive Sticky Navbar:** Automatically shrinks slightly on scroll; highlights the currently active page.
- **Universal Modal (`#enquiryModal`):** Automatically pre-fills selected Visa Type and Country when triggered from any card.
- **Interactive JavaScript:**
  - Dynamic current year updater.
  - Category filtering on destinations.
  - FAQ accordion.
  - Toast notification popup on form submissions.
  - Smooth scrolling and back-to-top button.
- **Floating WhatsApp Button:** Fixed at bottom right with direct wa.me link.
- **Asset Directory Structure:**
  - `images/logo.png`: Official logo.
  - `images/hero/`: High-resolution hero imagery.
  - `images/destinations/`: 12 high-definition destination photos.
  - `images/services/`: Service-specific photography.
  - `images/about/`: Corporate office & advisory imagery.
  - `images/b2b/`: Professional corporate partnership imagery.

## How to Run

1. Open `index.html` directly in any modern web browser (Google Chrome, Safari, Firefox, Edge).
2. All stylesheets (`css/style.css`), scripts (`js/script.js`), and images are linked relatively, functioning both offline and through any local web server (e.g. `npx serve .` or `python3 -m http.server 8000`).
